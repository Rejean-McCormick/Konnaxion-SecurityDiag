# External security references

SecurityDiag's baseline was aligned against primary vendor documentation current at pack creation:

- Django deployment checklist: https://docs.djangoproject.com/en/6.1/howto/deployment/checklist/
- Docker Engine security: https://docs.docker.com/engine/security/
- Docker Linux post-installation / docker group warning: https://docs.docker.com/engine/install/linux-postinstall/
- Docker Rootless mode: https://docs.docker.com/engine/security/rootless/
- OpenSSH `sshd_config`: https://man.openbsd.org/sshd_config
- Ubuntu automatic security updates: https://ubuntu.com/server/docs/how-to/software/automatic-updates/

These references do not replace environment-specific provider controls, incident response, or professional forensic review.
